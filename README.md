## 📌 Project Overview

This project is a part of the Digital Literacy course where I have taken the role of a **Student Digital Ambassador**. The aim of this project is to develop essential digital skills and help others understand how to use online platforms effectively, safely, and professionally.

Through this project, I explored various tools and platforms, created a professional digital presence, practiced coding and collaboration, learned proper email etiquette, and studied cybercrime awareness.


## ✅ Task Summary

### 🖼️ Task 1: Digital Literacy Infographic

Created a one-page infographic using Canva that explains the concept of digital literacy, safe internet practices, and useful tools for students. This task helped me understand how to present information visually in a simple and engaging way.


### 🌐 Task 2: Student Digital Portfolio

Developed my professional online presence by creating/updating profiles on platforms like GitHub and LinkedIn. I also created a GitHub profile README. This task helped me understand the importance of building a strong digital identity.


### 💻 Task 3: Coding & Collaboration Platforms

Solved a beginner-level coding problem on HackerRank and created a Google Form quiz on digital literacy. This task improved my problem-solving skills and introduced me to online collaboration tools.

### 📧 Task 4: Email Etiquette & Communication

Wrote two professional emails—one for requesting an assignment extension and another for internship inquiry. Also created a social media Do’s and Don’ts checklist. This task helped me learn proper digital communication.


### 🔐 Task 5: Cybercrime Awareness

Prepared a case study on cybercrime (such as phishing or UPI fraud) and created a prevention checklist. This task increased my awareness of online threats and how to stay safe on the internet.
